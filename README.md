# Sell the Pile

A clickable prototype for turning a pile of unworn clothes into draft listings
in one session: lay out up to six items, take one photo, and get a draft for
each item to finish later on Vinted, Kleinanzeigen, or both.

This is a Design Thinking prototype for testing, not a working product. Item
recognition is simulated, nothing is posted, and photos stay on the device.

Open it at https://iremleyla.github.io/sell-the-pile/
